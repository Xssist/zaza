Deployment instructions — GitHub token removed from frontend for security.

⚠ Security Notice
GitHub tokens must never be stored in browser-accessible files. Anyone who visits a page with a hardcoded token can read it in DevTools and get full repository write access.

Deploy options

1
Git push (recommended)
Open a terminal in your project folder and run:
git add . && git commit -m "update" && git push
2
GitHub Desktop
Open GitHub Desktop, commit your changes, and click Push origin.
3
Cloudflare Worker proxy (secure browser deploy)
Set up a free Cloudflare Worker that holds your token as an environment secret. The admin panel calls the Worker, not GitHub directly.
→ Cloudflare Workers docs

Admin saves are stored locally in localStorage and can be synced to GitHub via git push or a secure Worker proxy.
